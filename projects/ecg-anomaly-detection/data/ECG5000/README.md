- Downloaded: 2026-08-14
- SHA-256: `41F6DE20AC895E9CE31753860995518951F1ED42A405D0E51C909D27E3B3C5A4`

## Frozen project protocol

- One sequence is one interpolated heartbeat with 140 ordered scalar observations.
- One-class training uses only class 1 (Normal) from the official TRAIN split: 292 sequences, 40,880 time steps.
- Final evaluation uses the entire official TEST split without removal or reassignment: 2,627 normal and 1,873 anomalous sequences.
- Classes 2-5 are combined as the binary anomaly class only for evaluation.
- All preprocessing and model fitting use the normal training subset only.
- The official test split must not be used for feature, hyperparameter, or threshold selection.

## Known limitations

- The beats originate from a single patient, limiting external generalizability.
- The upstream PhysioNet annotations were generated by an automated detector and were not manually corrected.
