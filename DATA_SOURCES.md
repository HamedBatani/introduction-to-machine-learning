# Dataset and course-material provenance

I preserve the provided data needed to inspect the assignments, rather than claiming to have collected these datasets.

| Work | Source information available in the archive |
|---|---|
| CHW1 | Course-supplied synthetic probability, Gaussian, sensor, animal-species, stock, and text files; independent collection/provenance is not established |
| CHW3 | Course-supplied housing (`kc_house_data.csv`), discriminant, heteroskedastic, regression, and inverse-problem data; original licenses are not recovered here |
| CHW4 | `data/dataset_metadata.json` identifies scikit-learn breast-cancer, digits, wine, and diabetes datasets and the supplied train/validation/test variants |
| CHW5 Part 1 | Notebook links the [Heart Disease dataset page](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset); supplied `heart_disease.csv` is retained |
| CHW5 Part 2 | Supplied credit-card clustering table with 8,950 rows; source collection and license are not independently established by the local archive |
| ECG project | Supplied source note identifies the ECG5000 time-series archive and underlying PhysioNet BIDMC record; see [original provenance](projects/ecg-anomaly-detection/data/ECG5000/README.md) |

Question sheets, notebook prompts, template illustrations, and any copied assignment boilerplate are course-provided material. No blanket repository license is used to relicense these assets. Dataset descriptions above are based on the accompanying local metadata; they do not assert independent verification of all upstream licenses.
